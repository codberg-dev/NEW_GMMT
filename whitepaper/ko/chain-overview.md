# 2. 자이언트 맘모스 체인

## 개요
- **유형:** EVM 호환 퍼블릭 체인
- **Chain ID:** 8989 (0x231d)
- **네이티브 코인:** GMMT
- **스마트컨트랙트:** 지원(EVM)
- **익스플로러:** scan.gmmtchain.io
- **지갑:** GM Wallet (wallet.mammothlabs.io)

GMMT는 자체 메인넷 위에서 동작하며, EVM 호환이라 기존 Solidity 컨트랙트·툴을 최소 변경으로 이전할 수 있습니다.

## 최신화 계획
RWA 자체는 코어 체인 교체 없이도 가능하지만, 장기 경쟁력·보안·유동성을 위해 4개 트랙으로 최신화합니다.

| 트랙 | 범위 | 우선순위 |
| --- | --- | --- |
| A · 코어 체인 | 노드 클라이언트/EVM 버전 업그레이드 | 병행·리소스 |
| B · 개발환경 | 표준 툴(Hardhat/Foundry), 문서, RPC, faucet, 테스트넷 | **즉시** |
| C · 오라클 | RWA/DeFi용 가격 피드 | **선행** |
| D · 브릿지 & DEX | 자체 DEX + 메이저 체인 DEX 유동성 브릿지 | **고효과** |

> **[개발자 확인 필요]** 현재 노드 클라이언트/버전, EVM 버전, 배포 툴 상태, 오라클·브릿지 타당성, 밸리데이터 구성·업그레이드 절차.
