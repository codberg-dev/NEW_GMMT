# 2. 자이언트 맘모스 체인

## 개요
- **유형:** EVM 호환 퍼블릭 체인
- **Chain ID:** 8989 (0x231d)
- **네이티브 코인:** GMMT
- **기반:** BAS(BNB Application Sidechain), go-ethereum(geth) 포크
- **합의:** PoSA (Proof of Staked Authority)
- **블록타임:** 약 3초
- **밸리데이터:** 관리형 밸리데이터 세트 _(현재 수: 익스플로러/노드 운영 통해 확인)_
- **스마트컨트랙트:** 지원(EVM)
- **익스플로러:** scan.gmmtchain.io
- **지갑:** GM Wallet (wallet.mammothlabs.io)

GMMT는 자체 메인넷 위에서 동작합니다 — geth 기반 BAS 체인으로 PoSA 합의·약 3초 블록타임을 사용합니다. EVM 호환이라 기존 Solidity 컨트랙트·툴을 최소 변경으로 이전할 수 있습니다.

## 최신화 계획
RWA 자체는 코어 체인 교체 없이도 가능하지만, 장기 경쟁력·보안·유동성을 위해 4개 트랙으로 최신화합니다.

| 트랙 | 범위 | 우선순위 |
| --- | --- | --- |
| A · 코어 체인 | 노드 클라이언트/EVM 버전 업그레이드 | 병행·리소스 |
| B · 개발환경 | 표준 툴(Hardhat/Foundry), 문서, RPC, faucet, 테스트넷 | **즉시** |
| C · 오라클 | RWA/DeFi용 가격 피드 (계획) | **선행** |
| D · 브릿지 & DEX | 브릿지(운영 중) + 자체 DEX; 메이저 체인 DEX 유동성으로 확장 | **고효과** |

**상태:** 브릿지는 현재 운영 중이며, RWA/DeFi 가격 오라클은 도입 예정입니다. 정확한 노드 클라이언트/EVM 버전, 현재 밸리데이터 수, 업그레이드 절차는 노드 운영을 통해 확정합니다.
