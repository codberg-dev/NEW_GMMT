# 자이언트 맘모스 체인 (GMMT) — 백서 v4

> **가상자산을 넘어, 실물의 가치로.** 자이언트 맘모스 체인은 실물자산(RWA) 시대로 진입합니다 — **어떤 실물자산이든** 온체인으로 담는 **멀티 자산 체인**.

자이언트 맘모스 체인(GMMT)은 EVM 호환 퍼블릭 블록체인(Chain ID **8989**)입니다. 토큰이 전량 해제·유통된 국면을 지나, GMMT는 이제 분명한 새 방향으로 **재도약**합니다: 실물 경제의 자산을 온체인 인프라와 연결해 그 가치를 **투명하고, 검증 가능하며, 지속가능하게** 만드는 것입니다.

이 백서(v4)는 그 방향 — 비전, 기술, RWA 프레임워크, 토크노믹스, 생태계, 로드맵, 리스크와 안전장치 — 를 설명합니다.

> **상태:** 초안(v4). 수치와 계획은 현재 재도약 기준이며, 상품·파트너·온체인 파라미터가 확정되는 대로 업데이트될 수 있습니다. 본 문서는 투자 자문이나 증권 청약을 구성하지 않습니다.
